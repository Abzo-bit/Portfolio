# WhatsApp Clone

## Description
Application de messagerie instantanée moderne avec fonctionnalités avancées.

## Fonctionnalités principales
- Messagerie en temps réel
- Interface moderne et responsive
- Notifications push
- Authentification utilisateur

## Technologies utilisées
- React
- Node.js
- Socket.io
- MongoDB
