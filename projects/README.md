# 📁 Structure des Projets

Ce dossier contient vos vrais projets pour remplacer le contenu factice du portfolio.

## 📂 Organisation recommandée :

```
projects/
├── whatsapp-kaayjob/          # Projet WhatsApp Clone
│   ├── screenshots/           # Captures d'écran
│   │   ├── screenshot1.png
│   │   ├── screenshot2.png
│   │   └── mobile-preview.png
│   ├── demo-link.txt          # Lien de démonstration
│   ├── github-link.txt        # Lien GitHub
│   ├── description.md         # Description détaillée
│   └── technologies.txt       # Liste des technologies
├── autre-projet1/             # Autres projets
└── autre-projet2/
```

## 📝 Format des fichiers :

### description.md
```markdown
# Nom du Projet

## Description
Description détaillée du projet, ses fonctionnalités, etc.

## Fonctionnalités principales
- Fonctionnalité 1
- Fonctionnalité 2
- Fonctionnalité 3

## Technologies utilisées
- Tech 1
- Tech 2
- Tech 3

## Défis rencontrés
Description des défis techniques et solutions apportées.
```

### technologies.txt

## 🚀 Comment intégrer au portfolio :

Une fois vos projets ajoutés ici, je modifierai le fichier `src/components/Projects.js` pour :
- Utiliser vos vraies captures d'écran
- Liens GitHub corrects
- Descriptions authentiques
- Liens de démo fonctionnels

## 📋 Prochaines étapes :
1. Ajoutez vos projets dans ce dossier
2. Je mettrai à jour le composant Projects.js
3. Test et validation
